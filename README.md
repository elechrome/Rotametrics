# Rotametrics

동영상 기반 회전 각속도 측정 웹앱.
자동차 시트백처럼 회전운동을 하는 물체를 아이폰으로 촬영한 뒤,
영상 위에서 **회전중심 → 시작점 → 끝점** 3점을 터치로 지정하면
두 직선 사이의 각도와 경과 프레임 수로 각속도(deg/s)를 계산합니다.

순수 HTML/CSS/JS — 빌드 도구·외부 라이브러리 없음. 모든 처리는 브라우저 안에서 이루어지며
동영상이 서버로 업로드되지 않습니다.

## 실행

```bash
cd Rotametrics
python3 -m http.server 8000     # 또는 npm start
```

- **Mac에서**: 브라우저로 http://localhost:8000 접속
- **아이폰에서**: 같은 Wi-Fi에서 Safari로 `http://<Mac의 IP>:8000` 접속
  (Mac IP 확인: `ipconfig getifaddr en0`)
  - Safari 공유 버튼 → **홈 화면에 추가** 하면 아이콘으로 실행 가능
  - HTTPS로 배포하면 완전한 PWA(오프라인 동작 포함)로 설치됩니다

## 사용 방법

1. **동영상 불러오기** — 파일 FPS가 자동 감지됩니다 (메타데이터 → 재생 추정 → 수동 선택 순서)
2. **촬영 FPS 확인** — 슬로우모션을 일반 파일(예: 30fps)로 내보낸 영상이라면
   촬영 FPS를 실제 값(예: 240)으로 선택하세요. 실제 사건 시간 기준으로 환산됩니다.
3. **① 회전 중심** 터치 지정 → 확정
4. **② 시작 프레임**으로 이동(±1/±10 프레임 버튼) 후 **시작점** 지정 → 확정
5. **③ 끝 프레임**으로 이동 후 **끝점** 지정 → 확정하면 각속도가 계산됩니다
- 한 손가락 드래그: 점 미세 조정 (돋보기 표시) / 두 손가락: 화면 확대·이동
- 결과는 **기록에 저장** 후 CSV로 내보낼 수 있습니다

### 계산 방식

```
프레임 수   Δframes = (끝 미디어시각 − 시작 미디어시각) × 파일FPS
실제 시간   Δt = Δframes ÷ 촬영FPS        ← 슬로우모션 보정
각도        θ = ∠(중심→시작점, 중심→끝점)   (atan2, 방향 포함)
각속도      ω = |θ| ÷ Δt   [deg/s]
```

가정: 카메라가 회전 평면과 수직으로 촬영, 측정 구간 회전량 180° 미만.

## 테스트

```bash
npm test        # 계산/FPS 파서 단위 테스트 (node)
```

측정 정확도 검증: `http://localhost:8000/tests/testvideo.html` 에서
각속도를 아는 회전 영상(기본 45 deg/s)을 생성해 앱에서 측정값과 비교하세요.

## 구조

```
index.html            단일 페이지 UI
css/app.css           모바일 우선 스타일
js/app.js             단계 진행 상태 머신, UI 배선
js/video.js           프레임 스텝, rVFC 기반 프레임 시각 추적
js/fps.js             MP4/MOV 메타데이터 파싱 + 재생 추정 폴백
js/picker.js          터치 3점 선택, 핀치줌/팬, 돋보기
js/measure.js         각도/각속도 계산 (순수 함수)
js/history.js         localStorage 기록, CSV 내보내기
manifest.webmanifest  PWA 매니페스트
sw.js                 서비스워커 (HTTPS 배포 시 오프라인 캐시)
tests/run.mjs         단위 테스트
tests/testvideo.html  검증용 회전 영상 생성기
```
